# download-online-video-s

A simple web app that lets you paste a link and play videos, music, images, and other embeddable media in one place.

## Features
- Video playback for direct links like MP4/WebM
- Audio playback for MP3/WAV/etc.
- Image display for JPG/PNG/GIF/SVG
- Embedded playback for common site links and other supported media
- Clean single-page interface

## Run it locally
1. Open `index.html` in a browser, or
2. Serve the folder with a local web server:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```
